
# MY Bharat Hackathon - Hack for Social Cause
## Project Name: Explore Una (Rural Livelihood Dashboard)
### Theme: Rural Development & Livelihoods

## 📌 Project Overview
Explore Una is a frontend web prototype specifically designed to drive **Rural Development and Sustainable Livelihoods** in the rural and semi-urban blocks of Una district, Himachal Pradesh. Centered around major pilgrimage destinations like the Chintpurni Mata Temple, this digital platform bridges the urban-rural economic divide by connecting tourists and pilgrims directly with grassroots service providers.

The primary social cause is to create alternative non-farm livelihood opportunities for rural community members—including small homestay owners, village guides, and local street-food vendors—thereby enhancing family incomes, promoting rural entrepreneurship, and mitigating distress migration to urban centers.

## 💻 Tech Stack Used
* **HTML5:** Structured semantic markup for seamless user accessibility.
* **CSS3:** Responsive UI layouts tailored to look great on mobile devices used by rural travelers.
* **JavaScript (ES6):** Interactive map click configurations and dynamic logic to display local business directory lists.

## 🚀 Key Features for Rural Livelihoods
* **Grassroots Economic Integration:** Directly displays small, budget-friendly rural hotels, homestays, and regional food stalls near major tourist clusters to bypass middlemen.
* **Block-wise Regional Discovery:** Focuses on the balanced development of distinct rural and hilly blocks like Amb, Gagret, Haroli, and Bangana, shifting tourist traffic to interior villages.
* **Livelihood Preservation Tool:** Serves as a digital directory for localized hospitality micro-enterprises that lack heavy budgets for mainstream marketing.
* **Real-time Navigation & Weather:** Empowers travelers to safely explore rural terrains with integrated live maps and localized weather dashboards.

## 🛠️ How to Run this Project Locally
As a pure, lightweight frontend application, it runs instantly without any complex server configurations:
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open the project root folder.
3. Double-click the `index.html` file to launch the functional dashboard directly in your web browser.
